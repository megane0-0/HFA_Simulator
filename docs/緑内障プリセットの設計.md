# 緑内障プリセットの設計

緑内障プリセットの値をどう決めたか、病期をどう検証したかの記録です。**プリセットを作り足す・値を調整するときに読んでください。**

日常的に必要な事項（表が右眼向きであること、左眼で x を反転すること、単調性の不変条件、コピーは反転しない仕様）は [CLAUDE.md](../CLAUDE.md) にあります。この文書はその背景と検証手順を扱います。

## 正常部の値

中心32dB から周辺28dB を正常とみなしています。偏心度 r（度）に対して次式です。

```
N = round(33 − 0.18r)
```

周辺をレベル0の境界である**25dB にすると、補間で欠損が広くにじみ出ました**。`levelForDb` の境界ぎりぎりに置くと、IDW補間の途中の値がレベル1側へ落ちてしまうためです。境界から3dB 離して28dB にしています。

この式は表の値そのものではなく、**TD を計算するための基準**でもあります。値を変えると後述の MD・p5・p1 がすべてずれるため、変更する場合は3病期をまとめて作り直してください。

## 病期の決め方

病期は Hodapp-Parrish-Anderson 分類を目安にしています。

| 病期 | HPA の目安（MD） |
|---|---|
| 初期 | −6dB より良い |
| 中期 | −6 〜 −12dB |
| 後期 | −12dB より悪い |

**HFA の年齢別正常データベースは使わない簡易計算**です。実機の統計値とは一致しません。教育用に「それらしい」分布を作るための目安として使っています。

## 近似チェックの手順

上記の正常値 N を基準に、次を計算して病期の妥当性を確かめます。

- **TD** = 値 − N
- **MD** = 盲点2点を除く74点の TD の単純平均
- **GH** = TD の85パーセンタイル

有意点の判定に使う確率の目安は、偏心度によって変えています。

| 偏心度 | p5 | p1 |
|---|---|---|
| 10°未満 | ≤ −3 | ≤ −5 |
| 10〜20° | ≤ −4 | ≤ −6 |
| 20°以上 | ≤ −5 | ≤ −8 |

## 3病期の検証結果

現在の `GLAUCOMA_OD` を上記の手順で計算した値です。プリセットを変更したら、この表を作り直してください。

| 病期 | MD | p5 | p1 | 中心5° |
|---|---|---|---|---|
| 初期 | −2.03 | 10点 | 8点 | 正常 |
| 中期 | −6.95 | 28点 | 19点 | 最小18dB |
| 後期 | −18.12 | 55点 | 51点 | — |

中期の p1 が19点なのは、HPA の中期の基準である「p1 が20点未満」の**境目に意図的に寄せた**ものです。ここを超えると後期寄りの分布になります。

## 想定している病型と、増やすとき

3種はいずれも**上方から進行する典型的な開放隅角緑内障**です。下方から進行する例や、正常眼圧緑内障に多い中心寄りの暗点は用意していません。

各病期の視野の特徴は [README.md](../README.md) の「緑内障プリセットについて」にあります。

病型を増やす場合は、同じ表形式で別の stage として足せます。`GLAUCOMA_OD` に鍵を追加し、`PRESETS` と `<optgroup>` に登録するだけです。左眼での反転は `glaucomaPreset` が共通で処理するため、表は右眼向きに1つ書けば足ります。
