# FOVE で試すときの手順書

HFA 視野シミュレータ VR版を FOVE（FOVE0 / FOVE480）で初めて動かすための、1ステップずつの手順です。全体の説明は [README.md](README.md) にあります。

このプログラムは Unity でも実機でもまだ動かしていません。そのため手順を **「PC だけで確認」→「FOVE をつないで確認」** の2段階に分けています。先に PC だけで動くことを確かめておくと、うまくいかないときに原因がプログラム側か FOVE 側かを切り分けられます。

Unity と FOVE のメニュー名・フォルダ名は記憶に基づいて書いています。画面の表記が違うときは、近い名前のものを選んでください。

## 用意するもの

- Windows の PC（FOVE が動作する GPU を積んだもの）
- FOVE 本体。**USB はハブを通さず PC に直接つなぐ**（FOVE480 の公式の注意）
- FOVE のランタイム（FOVE の設定ソフト）。v1.4 以降
- Unity Hub と Unity 2021.3 LTS
- 360度の写真（正距円筒図法、横:縦 = 2:1、横 4096px 以上を推奨）。なくても確認用の模様で試せます

## 第1段階: PC だけで確認する（FOVE 不要）

### 1. プログラムを手元に置く

1. https://github.com/megane0-0/HFA_Simulator/pull/9 を開く
2. ブランチ `claude/awesome-mendel-ppbobz` のページへ移動し、緑の「Code」→「Download ZIP」で保存して展開する（PR をマージした後なら `main` からで構いません）
3. 展開したフォルダの中に `vr/HfaVr` があることを確認する

### 2. Unity のプロジェクトを作る

1. Unity Hub で「New project」を押す
2. エディタのバージョンに 2021.3 を選ぶ
3. テンプレートは **「3D」**（「3D (URP)」や「3D (HDRP)」ではないもの）を選ぶ
4. プロジェクト名を `HFA_VR_FOVE` などにして作成する

### 3. プログラムを入れる

1. エクスプローラーで `vr/HfaVr` フォルダをまるごとコピーする
2. Unity の Project ウィンドウの `Assets` に貼り付ける（`Assets/HfaVr/Scripts` と `Assets/HfaVr/Resources` ができる）
3. 読み込みが終わったら、**Console ウィンドウに赤いエラーが出ていないか**を見る

ここで赤いエラーが出たら、その文面をそのまま送ってください。特に `.shader` の名前が入ったエラーは、未コンパイルだったシェーダーの問題です。

### 4. シーンを用意する

1. 最初から開いている SampleScene をそのまま使う
2. Hierarchy の `Main Camera` を選び、Inspector の Position を (0, 0, 0)、Rotation を (0, 0, 0) にする
3. Hierarchy の何もない所を右クリック →「Create Empty」で空の GameObject を作り、名前を `HFA` にする
4. `HFA` を選び、Inspector の「Add Component」で **`Hfa Vr App`** を検索して付ける（この段階では FOVE 用ではなく、共通の本体を使います）

### 5. 再生して確かめる

再生ボタンを押し、Game ウィンドウを一度クリックしてから、次を順に確かめます。

| 番号 | 操作 | こうなれば正常 |
|---|---|---|
| 5-1 | 何もしない | 空と地面、10度ごとの白い格子、色の柱が見える。下に操作の案内が数秒出る |
| 5-2 | マウスの右ボタンを押したまま動かす | 見回せる |
| 5-3 | M → P を7回 → Shift+Enter → M | 緑内障中期が両眼に入る（パネルの表示が「緑内障 中期」になってから Shift+Enter） |
| 5-4 | E を押して「右眼（OD）のみ」にし、マウスを動かす | マウスの位置の**左上**がぼけ、マウスについてくる |
| 5-5 | E を押して「左眼（OS）のみ」にする | ぼける場所が**右上**に変わる |
| 5-6 | X | ぼけが消えて元の映像になる。もう一度押すと戻る |
| 5-7 | M でパネルを出し、マウスを点に合わせて Space | その点の色と数字が変わる |
| 5-8 | 再生を止めて、もう一度再生する | 5-3 や 5-7 で入れたデータが残っている |

ここまで通れば、表示と入力のしくみは動いています。通らない項目があれば、番号と、実際にどう見えたか（できれば Game ウィンドウの画面写真）を送ってください。

## 第2段階: FOVE をつないで確認する

### 6. FOVE のランタイムを用意する

1. FOVE 本体を PC につなぐ
2. FOVE のランタイムを起動し、本体が認識されていることを確かめる
3. ランタイムの画面から視線の較正（キャリブレーション）を一度済ませる

### 7. FOVE の Unity プラグインを入れる

1. https://github.com/FoveHMD/UnityPlugin の Releases から、最新（v4.5 系）の `.unitypackage` をダウンロードする
2. Unity のメニューで「Assets」→「Import Package」→「Custom Package...」を選び、そのファイルを指定して「Import」を押す
3. Console に赤いエラーが出ていないかを見る

### 8. FOVE 用の設定に切り替える

1. メニューの「Edit」→「Project Settings」→「Player」→「Other Settings」を開く
2. 「Scripting Define Symbols」の欄に `HFA_FOVE` を追加して「Apply」を押す（すでに何か入っていれば、`;` で区切って足す）
3. 再コンパイルが終わるのを待ち、Console に赤いエラーが出ていないかを見る

ここでエラーが出た場合は、FOVE プラグインの API が想定と違っています。文面を送ってください。

### 9. カメラを FOVE 用に入れ替える

1. Hierarchy の `Main Camera` を削除する
2. Project ウィンドウで FOVE プラグインのフォルダ（`Assets/FoveUnityPlugin` の中の Prefabs）から **「Fove Interface」** のプレハブを Hierarchy にドラッグする
3. 置いた Fove Interface を選び、Inspector の上部の Tag を **`MainCamera`** にする
4. Position を (0, 0, 0)、Rotation を (0, 0, 0) にする

### 10. 入口を FOVE 用に付け替える

1. Hierarchy の `HFA` を選ぶ
2. Inspector で `Hfa Vr App` の右上のメニュー（︙）→「Remove Component」で外す
3. 「Add Component」で **`Hfa Vr Fove`** を付ける

### 11. かぶって確かめる

再生ボタンを押し、FOVE をかぶります。操作は PC のキーボードで、もう一人が行うと楽です。

| 番号 | 操作 | こうなれば正常 | だめなとき |
|---|---|---|---|
| 11-1 | 何もしない | ヘッドセットの中に 5-1 と同じ模様が立体的に見え、頭を回すとついてくる | 真っ暗ならランタイムの起動と接続を確認 |
| 11-2 | F2 | 左眼に赤み、右眼に青みがかかる（片眼ずつつぶって確かめる） | 両眼とも同じ色、または逆なら、左右の判定が効いていません。連絡をください。それまでは E で「右眼のみ」「左眼のみ」を使えば試せます |
| 11-3 | F2 で戻し、V | 見ている場所に黄色い小さな輪が出て、視線についてくる | 輪が頭の正面から動かなければ、視線が取れていません。G を押して表示が「視線追跡（FOVE）」になっているか確認 |
| 11-4 | 格子の交点をいくつか見る | 輪が見ている交点とほぼ重なる | 1度以上ずれるなら F1 で較正をやり直す |
| 11-5 | M → P で「緑内障 中期」→ Shift+Enter → M → E で「右眼（OD）のみ」 | 見ている場所の左上がぼけ、視線を動かすとついてくる | ついてこなければ 11-3 を確認 |
| 11-6 | E で「左眼（OS）のみ」 | ぼける場所が右上に変わる | |
| 11-7 | E で「左右それぞれの眼」 | 片眼ずつつぶると、右眼では左上、左眼では右上がぼける | 11-2 がだめな場合はここもだめです |
| 11-8 | 視線をすばやく動かす | ぼけた部分が遅れずについてくる | 遅れが気になるときは、`HFA` の Inspector で Gaze Smoothing を 0 にする。逆にちらつくときは 0.05 に上げる |
| 11-9 | M でパネルを出し、点を見ながら Space | 見ている点が塗られる | 隣の点が塗られるなら較正のずれ。↑↓ キーでの数値調整は見ている点に効きます |

### 12. 自分の 360度写真を入れる

1. 再生を止める
2. Project ウィンドウの `Assets` の下に `StreamingAssets` フォルダを作り、その中に `360` フォルダを作る
3. `360` フォルダに写真（jpg / png）や動画（mp4）を入れる
4. 再生し、N キーで切り替わることを確かめる。正面の向きは `[` `]` キーで15度ずつ回せます

### 13. 見え方を Web版と見比べる

1. 同じ視野データ（たとえば緑内障中期）を Web版と VR版の両方に入れる
2. Web版の画角を 46度にして、ぼけの強さを見比べる
3. VR版が強すぎる・弱すぎると感じたら、`HFA` の Inspector の Blur Deg（レベル1〜4のぼかし幅、単位は度）を調整する
4. 視野30度より外の扱いは O キーで切り替えて、説明に使いやすいものを選ぶ

ここで決めた値を教えてもらえれば、既定値として書き換えます。

### 14. Unity なしで起動できる形にする（任意）

1. メニューの「File」→「Build Settings」を開き、「Add Open Scenes」を押す
2. Platform が「Windows, Mac, Linux」になっていることを確かめて「Build」を押し、保存先のフォルダを選ぶ
3. できた `.exe` を、FOVE のランタイムを起動した状態で実行する

## うまくいかないときに送ってほしいもの

- 何番の手順で止まったか
- Console の赤いエラーの文面（1行目だけでなく全体）
- 見え方がおかしいときは、Game ウィンドウの画面写真と、どう見えるはずだったか
- Unity のバージョン、FOVE の機種（FOVE0 か FOVE480 か）、ランタイムと Unity プラグインのバージョン

## 体験してもらう前に

- 医療機器ではなく、診断・治療の根拠には使えないことを伝える
- 表示は視線を固定した瞬間の見え方で、実際の日常は眼の動きで補っているぶん、これより良いことが多いと伝える
- VR 酔いが出たらすぐに外してもらう。最初は座った状態で、短時間から始める
